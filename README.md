# Otoya 🎧

Otoya is a real-time collaborative music experience and audio visualizer, reimagined with cutting-edge tech:
- **Frontend:** Next.js + Tailwind CSS
- **Backend:** Bun + WebSocket server
- **Monorepo:** Turborepo architecture

## 🛠️ Features
- 🔊 Audio sync across users
- 🎨 Live visual effects
- 🚀 Blazing fast performance with Bun

## 📦 Tech Stack
- Next.js 15 (frontend)
- Bun (server runtime)
- TailwindCSS + Shadcn/ui
- Turborepo (monorepo management)

---

## 🚀 Getting Started

```bash
bun install
bun dev
```

Visit the frontend at [http://localhost:3000](http://localhost:3000)
